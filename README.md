# Low Poly 3D Assets — One Page Website

Static HTML/CSS/JS website prepared for GitHub Pages.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open Settings → Pages.
4. In "Build and deployment", choose "Deploy from a branch".
5. Select branch `main` and folder `/ (root)`.
6. Save. GitHub will provide a public URL.

## Replace content
- Studio email: search for `hello@example.com` in `index.html`.
- Asset cards: replace placeholder blocks with your own images later.
- Brand name: replace `LOW POLY / 3D ASSETS` text with your final studio name.

## Optional real images
If you later add renders, put them into `/assets/` and use:
`<img src="assets/your-image.jpg" alt="...">`
inside the `.asset-preview` blocks.
